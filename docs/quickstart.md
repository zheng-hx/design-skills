# 快速上手

> 给**装好之后的使用者**看的。维护者请看 [多 AI 工具安装指南](install-by-tool.md) 与 [开发待办](todo.md)。

---

## 你只需要记住三件事

```text
/design-router  我要做一个新品牌，官网和包装都要       ← 不知道找谁、一次要做好几样
/ui-design      帮我做登录页的界面稿                   ← 知道找哪个工种
/design-any     帮我看看这个展台的动线                 ← 长尾工种，没有专属技能
```

命令不用背：直接说人话，工具会按描述挑技能。拿不准就用 `/design-router`，它只负责分流、不出稿。

---

## 第一次用，三步

**第 1 步 · 生成**（只做一次）

```text
/apply-design-skills
```

它只问一件事：**这次启用哪些工种**。默认 19 个高频工种，直接回车就行。
想要精简子集可以说「只要 UI 和品牌」，想全启用说「全部」。

**第 2 步 · 注册**（只做一次）

```text
/install-design-skills
```

扫描项目里已有的 AI 工具目录，检测到的都注册，没检测到的一律不动。之后命令立即可用。

**第 3 步 · 干活**

直接说需求。技能会先问你**一个**问题，按你的回答往下走，不会甩一张 20 项的表单。

## 会话会怎么走

```text
技能：先确认一个：这次最终要交出什么？给谁用？
你  ：官网首页视觉稿，给市场部下周评审
技能：明白。现有品牌规范或设计系统能给我吗？（没有我就按「待补」处理，不猜）
你  ：有，在 design/brand.md
技能：……（按你的回答继续，一次一问）
技能：## 本轮结论  ← 直接贴在对话里
      | 核心目标 | … | 关键约束 | … | 待确认 | … |
      请确认，确认后我再出稿。
```

**注意这两个停点**：结论卡出来后要点头，最终产物出来后也要点头。
没点头之前技能不会写「已完成」，这是刻意的，不是卡住了。

## 常见问题

**Q：一次要做好几样怎么办？**
用 `/design-router`。它会拆成一张路由卡（谁先谁后、谁依赖谁），再交给各工种分别出稿，
不会混成一份四不像。

**Q：我要的工种没在命令列表里？**
说明它是长尾工种（室内、建筑、服装、珠宝、Logo、印前、图标……）。用 `/design-any`，
它第 0 步会先说清「能给什么、不能给什么」——比如施工图、打样件、可印制原文件给不出来。

**Q：能不能直接出图 / 出成片？**
宿主 AI 工具自带生成能力时可以直接用，但出图后要过一遍 AI 常见缺陷排查；
字体、图片、图库素材的授权要核验，拿不到就标「待授权」，不会默认你能商用。

**Q：我的作品会被升级覆盖吗？**
不会。`.design/artifacts/` 是用户区，升级绝不覆盖、绝不删除。管理区 `.design/` 会替换式重渲染。

**Q：多个人用不同 AI 工具？**
都扫到就都装。想确认跑了哪些，看工具目录下的 `.design-managed.json`。

**Q：换工种集合 / 更新版本？**

```text
/update-design-skills       或直说「更新设计技能」
```

升级会重新生成、重新注册，但你自己的技能、别人包的注册项、以及 `artifacts/` 都不动。

---

## 几条不该越过的线

- 没有依据的数据、审批人、期限，技能会写 `[缺失·阻塞]`，不会替你编；
- 涉及界面会给可访问性的**实测值和条款号**，不会写「看起来还行」；
- 每种界面状态（加载 / 空 / 错 / 权限不足……）都要覆盖，不会「异常流程以此类推」；
- 关键内容贴在对话里，不会只丢一个文件路径让你自己点开。
