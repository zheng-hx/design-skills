# 交付最小集（全工种通用）

> **作用域**：**所有工种**（core / extended 一视同仁）。每交付一件东西就对照一次。
> **性质**：**硬门禁**——本工种最小集缺任何一样，视为**未完成**，不得交付、不得写「已生成完成」。
> **口径**：门禁、流水线骨架、评审智能体、交付最小集是**全工种通用**的；工种只差「细节填什么」。

---

## 通用四问（不分工种）

任何交付物都要同时回答四问，缺一即未完成：

| # | 四问 | 含义 | 反例 |
|---|---|---|---|
| 1 | **结构** | 它由什么组成、怎么组织，看得懂 | 只给一句「做了个页面」 |
| 2 | **呈现** | 能直接看到成品本身（图 / 稿 / 模型 / 预览），不是只有文字 | 只有文字线框，一张图没有 |
| 3 | **规格** | 别人能照着做出来：尺寸、参数、变体、状态、材料 | 「主按钮，主色」 |
| 4 | **语言** | 一致的调性与规则（配色 / 字体 / 风格 / 术语），并说明为什么适合 | 「简洁大气」 |

> 四问落到文件，就是 `templates/` 里的产物；落到对话，就是收口卡片。**只有文件路径不算交付。**

## 各工种最小交付对照（缺一不可）

| 种类（工种） | 最小交付 |
|---|---|
| **界面**（ui / product / web / ecommerce / interaction） | 页面结构；页面效果（渲染截图 / SVG / HTML 可视稿）；组件规格（逐组件：尺寸、字号字重、间距、圆角、变体、全部状态、禁用规则、触控尺寸）；视觉语言 7 项（配色、字体、间距、圆角、阴影、图标、调性） |
| **体验**（ux） | 用户旅程 / 任务流 / 信息架构；关键路径原型或线框（能点优先）；可用性验证记录（样本、方法、结论与证据）；可执行建议（按优先级） |
| **品牌 / 视觉**（brand / visual） | 方向提案（≥3 个方案对比与取舍理由）；标志或主视觉成品（矢量 / 高分辨率）；色彩与字体规范；≥3 个真实场景应用示例；视觉语言 7 项 |
| **平面 / 字体 / 信息图**（graphic / typography / infographic） | 成品稿（可印制 / 可导出）；版式与网格说明；字体与色彩规范；输出规格（尺寸、出血、色彩模式、导出格式）；字体与素材授权核对 |
| **插画**（illustration） | 风格样例；成套成品（≥3 张且主次一致）；尺寸与用途清单；源文件分层说明；授权与来源 |
| **包装**（packaging） | 结构图 / 刀版；视觉稿（含各展示面）；材料与工艺说明；信息合规（条码、法规、警示）；打样说明 |
| **空间 / 3D**（3d） | 平面 / 立面或 3D 视图；材料与灯光说明；关键节点或视角；交付格式与精度 |
| **动效**（motion） | 关键帧 / 分镜；时长与缓动规格；导出规格（分辨率、帧率、格式）；降级与性能说明 |
| **设计系统**（systems） | 令牌与组件清单；使用规则与反例；版本与变更记录；采用与迁移说明 |
| **研究**（research） | 研究问题与方法；样本与证据（原始材料）；结论与局限；可执行建议 |
| **可访问性**（accessibility） | 条款级核验结果（逐条）；问题清单与优先级；复验记录；报告与责任人 |
| **AI 生成**（ai-generated） | 提示词与参数；多轮候选与筛选理由；缺陷清单逐项核查；授权与来源标注 |
| **电商**（ecommerce） | 卖点排序；主图与详情结构；多尺寸切片规格；合规与禁用词检查 |

> `extended` 工种由 `/design-any` 承接时，**同样按本表最接近的一行**执行；本表没有对应行的，
> 按通用四问自建最小集，并在产物里注明「按通用四问处理」。

## 组件规格怎么写（界面类）

一个组件一张表，**写到开发不用问**：

```markdown
### 主按钮
| 项 | 规格 |
|---|---|
| 尺寸 | 高 48px，水平内边距 24px，最小宽 120px |
| 圆角 | 8px |
| 字号 / 字重 | 16px / 600 |
| 变体 | 主要 / 次要 / 危险 / 文字 |
| 状态 | 默认 / 悬停 / 按下 / 聚焦 / 禁用 / 加载 |
| 禁用规则 | 必须同时说明原因 |
| 触控 | ≥44×44px |
```

**变体与状态要列全**——「一个按钮」通常有 4 个变体 × 6 个状态。

## 与产物模板的对应（界面类示例，其他工种同理）

| 最小集 | 落在哪个产物 |
|---|---|
| 结构 | `templates/design-spec.md` §2 / `templates/wireframe.md` |
| 呈现 | `templates/design-spec.md` §3 页面效果（可视稿） |
| 规格 | `templates/component-spec.md`（逐组件表） |
| 语言 | `templates/design-tokens.md` + `design-spec.md` §7 |

> 四个小节任一为空或只有占位文字 → 该产物 `status` 不得进 `confirmed`。
