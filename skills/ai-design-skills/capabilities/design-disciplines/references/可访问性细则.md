# 可访问性细则（WCAG 2.2 AA）

> **作用域**: **按需参考**。做设计规格时对照；评审时逐条验收。
> **基线**: WCAG 2.2 Level AA（2023-10 发布，ISO/IEC 40500:2025）。合规以 2.x 为准，不要以 WCAG 3.0 草稿或 APCA 作为通过标准。

---

## 1. 对比度（最常出错）

| 项 | 要求 | 条款 |
|---|---|---|
| 正文文字 | ≥ **4.5:1** | 1.4.3 AA |
| 大字（≥24px，或 ≥18.66px 粗体） | ≥ **3:1** | 1.4.3 AA |
| UI 组件边界（输入框边框、开关、复选框） | ≥ **3:1** | 1.4.11 AA |
| 图形对象（图标、图表元素） | ≥ **3:1** | 1.4.11 AA |
| 焦点指示器 | ≥ **3:1** | 1.4.11 AA |

> 占位符文字、禁用态文字同样要可读——禁用态不豁免对比度（但可降低不透明度同时保持可辨认）。

## 2. 键盘与焦点

| 要求 | 说明 |
|---|---|
| 所有交互元素可 Tab 到达 | 不可跳过的"键盘陷阱" |
| 焦点**可见** | 有清晰轮廓，不能 `outline: none` 了事（2.4.7） |
| 焦点**不被遮挡** | 聚焦元素不能被固定头部/浮层盖住（**2.4.11 AA，WCAG 2.2 新增**） |
| 弹层焦点管理 | 打开时焦点移入，Esc 关闭，关闭后焦点归还触发元素 |
| 顺序合理 | Tab 顺序符合视觉顺序 |
| 拖拽有替代 | 拖拽排序必须提供非拖拽方式（**2.5.7 AA，新增**） |

## 3. 触控与目标尺寸

| 要求 | 条款 |
|---|---|
| 目标尺寸 ≥ **24×24 CSS px** | **2.5.8 AA（WCAG 2.2 新增）** |
| 推荐 ≥ **44×44** | 2.5.5 AAA（移动端实践建议） |

> 相邻目标之间要有间隔，否则误触率会上升。

## 4. 屏幕阅读器

- 用**原生元素**优先：`<button>`、`<label>`、`<dialog>`、`<details>`；原生能做的不要加 ARIA。
- 图标按钮必须有可访问名（`aria-label`），不能只有图标。
- **动态变化要播报**：金额变化、结果返回、错误出现 → `aria-live="polite"`（紧急用 `assertive`）。
- 表单：`label` 与控件用 `for`/`id` 关联；错误信息用 `aria-describedby` 关联到字段。
- 表格：用 `<th scope>` 表达表头，不要用样式加粗假装表头。
- **不要只用颜色传达信息**（1.4.1）：错误要同时有文字/图标，成功要同时有文案。

## 5. 文字与缩放

| 要求 | 说明 |
|---|---|
| 200% 缩放不丢失内容与功能 | 1.4.4 AA |
| 不锁定文字方向/缩放 | 不要 `user-scalable=no` |
| 文字间距可调 | 1.4.12 AA |
| 不用图片承载文字 | 除非是 logo |

## 6. 动效与动画

| 要求 | 说明 |
|---|---|
| 尊重 `prefers-reduced-motion` | 降低或关闭动效，不平移、不缩放 |
| 闪烁不超过 3 次/秒 | 2.3.1 A |
| 动效不阻塞操作 | 允许跳过、允许关闭 |
| 自动播放内容可暂停 | 2.2.2 A |

## 7. 认知与一致性

| 要求 | 条款 |
|---|---|
| 同一功能在各页面命名一致 | 3.2.4 AA |
| 帮助入口位置一致 | 3.2.6 A（新增） |
| **不要求重复输入已提供的信息** | 3.3.7 A（新增） |
| 不用纯记忆挑战做认证（无替代方式） | 3.3.8 AA（新增） |
| 错误提示说清哪里错、怎么改 | 3.3.1 / 3.3.3 A |

## 8. 评审验收清单

- [ ] 逐条核对对比度（工具测 + 肉眼在暗色模式下看）
- [ ] 只用键盘走完主流程，焦点全程可见且不被遮挡
- [ ] 320px 宽度 + 200% 缩放内容不丢
- [ ] 所有图标按钮有可访问名
- [ ] 动态变化有播报
- [ ] 错误不只靠颜色表达
- [ ] 触控目标 ≥24×24 且相邻有间隔
- [ ] 开启 reduced motion 后动效正常降级
