# 立体与空间交付边界

> **作用域**：`3d-design`（core）与全部「空间与实体」域的 `extended` 工种
> （室内 / 建筑 / 工业 / 服装 / 展览 / 影视美术 / 家具 / 珠宝）经 `/design-any` 承接时必读。
>
> **这份文件的目的不是教怎么设计，而是把「AI 能交什么」划清楚。** 说清楚比给一堆漂亮话有用。

## 1. 总原则

立体与空间类工作的最终交付物几乎都**不是文档**：是施工文件、可生产文件、打样件、实体空间。
AI 能做的是前面的**决策、方案、规格与检查**，后面的**必须由对应专业的从业者与软件完成**。

> **禁止**把「生成了一份方案 / 渲染参数表」说成「已完成设计交付」。

## 2. 能交付 / 不能交付

| 能交付 | 不能交付 |
|---|---|
| 需求简报、场地与约束清单 | 施工图 / CAD / BIM 文件 |
| 参考与竞品分析（带出处） | 结构验算、荷载与消防计算 |
| 2–3 个方向提案与取舍 | 材料与工艺的实际性能测试 |
| 镜头脚本、构图与色彩脚本 | 打样件、模具、版型、镶嵌实物 |
| 材质 / 灯光 / 渲染参数表 | 最终可印制原文件、印厂签样 |
| 资产清单、版本与检查清单 | 资质报审、法规合规签署 |

## 3. 3D 建模与渲染（core 工种，可给规格）

`3d-design` 是有独立技能的 core 工种，因为它能给出**可复现的配置**而非假想成片：

- 交付：镜头脚本、模型与拓扑说明、材质与贴图清单、灯光与色彩管理、**渲染参数表 + 版本**；
- 参数要能复现：软件与版本、采样、分辨率、色彩空间、导出格式；
- 模型 / 贴图素材的来源与授权要记录，见 `许可与来源规范.md`；
- 宿主无 3D 生成能力时，明确说明「只给配置，不生成网格 / 贴图文件」。

## 4. 按域的必查约束

| 域 | 必查 | 典型不可交付 |
|---|---|---|
| 室内 / 建筑 / 景观 | 尺度、动线、消防疏散、无障碍、采光、材料防火等级 | 施工图、报审文件、结构验算 |
| 展览 / 舞美 / 影视美术 | 搭建限高、承重、消防、观众动线、镜头连续性 | 实景搭建、道具制作 |
| 工业 / 产品造型 | 人机尺寸、CMF、模具拔模与分件、装配公差 | 可生产文件、成本核算 |
| 服装 / 纺织 | 版型、面料缩率、号型体系、季节性企划 | 样衣、纸样文件 |
| 家具 | 尺度、结构连接、材料与五金、运输拆分 | 可加工图纸 |
| 珠宝 / 配饰 | 贵金属工艺、镶嵌结构、佩戴尺度与克重 | 起版、浇铸 |

## 5. 法规与资质

- **不臆造条款号**：不确定就标「待核验」，让用户找对应专业方确认；
- 涉及公共安全（消防、承重、疏散、电气）时，明确写「需具备资质的专业方复核」；
- AI 给的意见不得作为报审依据。

## 6. 边界声明模板

在动手前贴出来（`/design-any` 第 0 步强制）：

```text
「<工种>」属于线下实体工种。我能给：约束清单、参考分析、方向提案、规格与检查清单。
我不能给：施工/可生产文件、打样件、材料与结构验算、资质报审。
涉及消防、承重、疏散等公共安全项，需由有资质的专业方复核。
```

## 7. 与 `AI生成设计缺陷清单.md` 的关系

用 AI 生成概念渲染图是允许的，但要当作**方向沟通素材**，不是交付物：
标注「概念示意，非施工 / 生产依据」，并逐项排查生成缺陷（尤其透视错误、材质失真、结构不合理）。
