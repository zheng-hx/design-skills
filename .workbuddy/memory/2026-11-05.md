## SkillHub 发布最终闭环（1.0.1 已上线）

### 关键发现（按时间序）
1. GitHub 导入丢文件 → 根因：平台文件类型白名单（只收 md/py/json/yaml，恰 28 个）。
2. CLI `publish` 同样被服务端 400 拒收：`.tpl` 与无扩展名 `VERSION` 都不允许。
3. 结论：**平台硬约束 = 白名单**，包必须改名适配；CLI zip 打包本身无排除（改完名全量入库）。
4. 发布成功后 `search`/首次 `install` 仍显示 1.0.0 → 只是传播延迟/索引缓存，公开 API
   `/api/v1/skills/<slug>` 的 `latestVersion` 才是权威；稍后重装即得新版。
5. macOS `unzip` 解平台 zip 中文文件名乱码并卡交互提示——用 Python zipfile 正常，非真问题。

### 改名方案（架构不变，渲染产物名不变）
- `SKILL.md.tpl` → `SKILL.template.md`；`openai.yaml.tpl` → `openai.template.yaml`
- `templates/*.md.tpl` → `*.template.md`；`design.json.tpl` → `design.template.json`
- `VERSION` → `version.json`（`{"version": …}`）
- 7 个脚本同步改造：render / build-disciplines / verify-render / check-triggers / validate-package / audit-repo / sync-version
